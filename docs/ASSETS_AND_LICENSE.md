# Artwork and licensing

The reef artwork was adapted from an image supplied during development. **Permission to redistribute this material has not been verified.** Some sprite references were also supplied during development.

The HDL and support scripts are shared here for project documentation. No license is supplied, and public availability does not by itself grant reuse rights.

Before redistributing or licensing the imagery, verify ownership and permission, or replace the artwork with original/licensed alternatives. Python sanity tests are not hardware verification.
